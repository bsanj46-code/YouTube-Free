Ваш просмотр, ваши данные

Избранное хранится только в этом браузере. Между телефоном и планшетом оно не синхронизируется.

Видео воспроизводятся в официальном плеере YouTube. YouTube может показывать рекламу, обрабатывать данные просмотра и ограничивать доступность отдельных видео. Нажатие на видео загружает плеер и связывается с YouTube.

Веб-версия не блокирует рекламу и не обеспечивает фоновое воспроизведение. Кнопка полного экрана работает по нажатию. Поворот включает его автоматически, если это разрешает браузер; иначе плеер разворачивается внутри страницы.

Поиск по названиям пока открывается на YouTube. Затем вставьте ссылку на найденный ролик в строку поиска здесь.
